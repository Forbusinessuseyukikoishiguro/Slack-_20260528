# 🎨 Slack アイコン分割ツール

**ChatGPT で生成したグリッド画像を、Slack カスタム絵文字用に1枚ずつ切り出すブラウザツールです。**

> 仕事を1ミリハッピーにする Slack ステータスアイコンを、デザイン知識ゼロ・インストール不要で作れます。

---

## ✨ 機能

- 🖼️ **ドラッグ&ドロップ**でグリッド画像を読み込み
- 🔢 **グリッドレイアウト選択**（2×1 〜 3×3 など7種類）
- 👁️ **プレビュー上にグリッド線＋番号**をリアルタイム表示
- 📥 **個別ダウンロード**（アイコンカードをクリック）
- 📦 **ZIP 一括ダウンロード**
- 📐 全アイコンを **128×128px** に自動リサイズ（Slack 推奨サイズ）
- ⚡ **HTML 単体ファイル** — サーバー不要、インストール不要

---

## 🚀 使い方

### 1. ツールを開く

```
slack-icon-splitter.html をブラウザにドラッグ＆ドロップして開く
```

### 2. ChatGPT でグリッド画像を生成

ChatGPT の画像生成にこのようなプロンプトを投げます：

```
以下のSlackスタンプ用アイコンを 3×2 のグリッドで1枚の画像に作成してください。
白背景、シンプルな棒人間スタイル、日本語ラベル付き。

・出勤
・在宅勤務
・集中モード
・雑談OK
・定時で帰ります
・残業OK
```

> **ポイント**：まとめて1枚に出力させることで、スタイルが統一されます。

### 3. 画像をツールに読み込む

生成した画像をドロップゾーンにドラッグ＆ドロップ（またはクリックして選択）。

### 4. グリッドを選択

画像のレイアウトに合わせてボタンをクリック。プレビューにグリッド線が表示されます。

| 画像レイアウト | 選択するグリッド |
|---|---|
| 3列 × 3行（9個） | `3 × 3` |
| 3列 × 2行（6個） | `3 × 2` |
| 4列 × 1行（4個） | `4 × 1` |

### 5. ダウンロード

- **個別**：アイコンカードをクリック → PNG がダウンロードされます
- **一括**：「📦 ZIP でまとめてDL」ボタン → 全アイコンが ZIP になります

### 6. Slack に登録

1. Slack の「絵文字を追加」を開く
2. ZIP から各 PNG をドラッグ＆ドロップ
3. 絵文字名を設定して保存
